Documentación del Sistema

Arquitectura del Sistema

El Gemelo Digital 5G se compone de tres capas principales:

  • Capa de Ingeniería (MATLAB): Simulación de propagación con modelo Longley-Rice
  • Capa de Servidor (Spring Boot): API REST para gestión de datos
  • Capa de Usuario (Angular): Interfaz web con visualización Leaflet

Modelo de Propagación

Se utiliza el modelo Longley-Rice (ITM) para calcular las pérdidas de propagación, considerando:

  • Frecuencia de operación: 3.5 GHz (banda n78 5G FR1)
  • Datos de elevación SRTM con resolución 30m
  • Parámetros atmosféricos estándar
